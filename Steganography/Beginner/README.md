# Name

Ghost Sign

## Author

@justinforbes

## Overview

Pittsburgh is full of ghost signs: old advertisements painted on brick walls decades ago, faded but never quite gone. Our photographer found this one in the Strip District, and swears there was more painted on it than you can see now. Can you bring the rest of it back?

## Setup

Attach `files/ghost_sign.png` as a CTFd download. No hosted service is needed. Players can solve it with the local CyberChef (**Randomise Colour Palette** or **View Bit Plane**) or with any image editor (paint bucket fill, levels or curves).

`build/make_ghost_sign.py` regenerates the image (Pillow and the DejaVu fonts required). It is for organizers only; do not attach it.
